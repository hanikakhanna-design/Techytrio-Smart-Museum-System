# Techytrio-Smart-Museum-System
A smart museum where when a person enters the lights automatically turn on and when they try to get close to valuable gemstones a buzzer goes off alerting staff someone is trying to steal. If it malfunctions, for making sure the gem doesnt get stolen, there is a tilt switch on it which on tilting alerts the buzzer to buzz. Moreover, there is a water senser to detecs floods for safety. If water is in contact with it, the green led lights up. Furthermore, a sound sensor is present which prevents loud noise to not distract or disturb other tourists so the staff can tell them to speak softly.
